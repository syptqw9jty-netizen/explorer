# Dämmerungsrand

Ein ruhiges Fahr-, Flug- und Erkundungsspiel im Browser. Prototyp.

Spielen: Seite öffnen, Modus wählen. Auf dem iPhone in Safari über „Teilen → Zum Home-Bildschirm" als App installieren.

Modi
- Reise: nur fahren, 18 versunkene Städte, nichts kann passieren
- Flug: als Feuer- oder Wasserwesen Ringe fliegen, Städte entzünden oder erblühen lassen, gegen das andere Element
- Frei: offene Welt mit Auto und zu Fuß

Steuerung: ziehen lenkt, hochwischen gibt Schub, Kreis malen ist ein Trick, tippen ist Stoß bzw. Feuer oder Wasser.
Oben links tippen öffnet das Menü mit Karte und Einstellungen.

Technik: eine HTML-Datei, three.js r128 (MIT-Lizenz), kein Server, kein Tracking. Der Spielstand liegt nur im Browser.
