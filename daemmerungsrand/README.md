# Dämmerungsrand

Ein ruhiges Fahr- und Erkundungsspiel im Browser. Prototyp.

Spielen: Seite öffnen, tippen. Auf dem iPhone in Safari über „Teilen → Zum Home-Bildschirm" als App installieren.

- ziehen: Gas und lenken, nach unten ziehen: bremsen
- tippen: Stoß
- durch die Ringe fahren: schneller
- Knopf unten rechts: aussteigen / einsteigen

Technik: eine HTML-Datei, three.js r128 (MIT-Lizenz), kein Server, kein Tracking. Der Spielstand liegt nur im Browser.
